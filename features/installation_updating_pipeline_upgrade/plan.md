- **Общий статус:** `IN_PROGRESS`.

### `02_verified_staging`

- Coding session: `/root/stage02_verified_staging`, effort `high`.
- Предварительная независимая проверка: на Debian 13 и Ubuntu 24.04 (Compose 5.7.1, Engine 29.10.0) тестовый Compose сохранил работоспособность и прежний `.env` после отказов сертификата, Registry, расчётных дефицитов места/inode и успешного повтора временного сбоя по тому же манифесту. Проверка Docker-сети MTU 1280 на Debian получила 65 536 байт после прерывания первого запроса. Исторический PMTU blackhole и реальное исчерпание диска не моделировались.
- `ACCEPTED`: проверены закрепление релиза и эффективная конфигурация, сохранение секретов/алиасов, устойчивость частичной записи и принадлежность bootstrap-мастера. Независимо повторены Windows-тесты (71 прошёл, 6 Linux-only пропущены), Linux (41 прошёл) и Ruff. Штатный образ мастера собрался и без сети загрузил `VerifiedStaging`, `curl` присутствует. Полноразмерный продуктовый кандидат и реальные сбои ФС остаются в матрице этапа 10.

- Локальный коммит этапа: `cf5cef6`.

## Риски и оставшиеся действия

- Проверены SSH и sudo на выделенных Debian 13 и Ubuntu 24.04 (`linux/amd64`, systemd, 2 CPU, около 4 ГиБ RAM и 29,5 ГиБ корневая ФС). Пользователь подтвердил проверку на этих ресурсах без тяжёлой ETL-нагрузки. Docker Engine 29.10.0 и Compose 5.7.1 предустановлены; для ветки bootstrap без Docker и чистого восстановления нужен воспроизводимый сброс/чистый снимок. На удалённой ВМ сетевые отказы моделировать без потери административного канала. Данные доступа и отпечатки ключей не включать в Git.
- Доступ на запись в Git метаданные может потребовать разрешения среды. Коммиты адресные, без push. Интеграция UI/CI/CD/Distributor с остальными репозиториями проходит локально; продукты и клиенты не переключаются автоматически.
- Первый новый путь остаётся за явным выбором/тестовой конфигурацией, пока не подтверждены legacy и аварийное восстановление. Готовность релиза не заявляется без сквозной матрицы.
