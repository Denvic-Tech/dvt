- **Общий статус:** `IN_PROGRESS`.

Следующий этап начинается после независимой приёмки и сохранения предыдущего этапа, если Git и разрешения позволяют.

## Риски и оставшиеся действия

- Проверены SSH и sudo на выделенных Debian 13 и Ubuntu 24.04 (`linux/amd64`, systemd, 2 CPU, около 4 ГиБ RAM и 29,5 ГиБ корневая ФС). Пользователь подтвердил проверку на этих ресурсах без тяжёлой ETL-нагрузки. Docker Engine 29.10.0 и Compose 5.7.1 предустановлены; для ветки bootstrap без Docker и чистого восстановления нужен воспроизводимый сброс/чистый снимок. На удалённой ВМ сетевые отказы моделировать без потери административного канала. Данные доступа и отпечатки ключей не включать в Git.
- Доступ на запись в Git метаданные может потребовать разрешения среды. Коммиты адресные, без push. Интеграция UI/CI/CD/Distributor с остальными репозиториями проходит локально; продукты и клиенты не переключаются автоматически.
- Первый новый путь остаётся за явным выбором/тестовой конфигурацией, пока не подтверждены legacy и аварийное восстановление. Готовность релиза не заявляется без сквозной матрицы.
