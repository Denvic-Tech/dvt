# Локальная проверка этапа 09

| Проверка | Наблюдение |
| --- | --- |
| Изолированный DVT Gateway | `uvicorn services.gateway.main:app --host 127.0.0.1 --port 8200 --lifespan off --no-access-log` с абсолютным `PYTHONPATH`. Штатный генератор прочитал `http://localhost:8200/openapi-core.json`. Для файла с адресом по умолчанию Git diff пуст. |
| Защищённый bootstrap | Параллельный запрос с несовпадающим payload получает 409 с действующим ID. Идентичный запрос возвращает исходный ID даже при создании нового приложения manager. |
| Первичная настройка | До readiness server возвращает 409. Непарный запрос блокируется. Неверный Origin или отсутствующий заголовок CSRF даёт 403. Израсходованный код даёт 401. Невалидный email даёт 422 в `body.values.email`. |
| Обновление | Пользователь без роли суперпользователя получает 403. Вызов применения без подтверждения даёт 422. Подтверждение передаёт исполнителю прежний ID. |
| Диагностика | Тест проверяет отсутствие setup-кода, bootstrap-кода и служебного токена в защищённом документе. |
| Основной UI | Vitest проверяет отображение поля email, обязательность подтверждения в профиле и сохранение того же ID в плане и независимой ссылке. |
