# Независимая проверка локального кандидата

Ubuntu 24.04 LTS и Debian 13, linux/amd64, 2 vCPU, около 4 ГиБ RAM и
30 ГБ диска. Engine 29.10.0, Compose 5.7.1. Для прогона созданы отдельные
Docker/containerd с подтверждённым пустым кэшем, собственными bridge и
каталогом данных. Прежние установки оставались в штатном Docker. Использовались
отдельный корень Ed25519, TLS CA и сценарные данные.

## Закрепление поставки

- Исходники для сборки Linux amd64: DVT
  `7fe257b129adb329faea503e2e17af6eaf4d2be9` и Gitlink UI
  `543b246ce6abf673fc4a41943365f5d853650377`. Все восемь целей собраны
  штатным Bake из Git-архивов, Dockerfile UI и build context сохранены.
- Приватный TLS Registry выдал точные байты всех восьми OCI leaf. Skopeo
  сверил сжатые слои, измерил объём и inode. Мигратор использует Gateway.
  PostgreSQL и Valkey закреплены как Linux amd64 leaf. Исходный
  `bootstrap.py` имеет SHA-256
  `1a770a953c7b8f344b685408513e15110b4749876db7779395f5b382ad5c3a97`.
- Новый private Distributor выдал synthetic predecessor `1.23.99` и
  canonical RC `1.24.0-rc2` через доверенный HTTPS на обеих ВМ. Первый
  манифест RC `sha256:77b0413adaff153a0dad08e3a3d66a6902adb3c985cd9e4a9fe078e951366ce4`
  содержал ошибочный минимальный preparer `1.24.0`. RC установщик
  `1.24.0rc2` корректно отказал до развёртывания. После проверки изменили
  только тестовую политику совместимости, release ID и подпись. Рабочий RC
  получил digest
  `sha256:3befb0aeb9c55eec995fa192e218b7da210c9d842457006ec731f34ce523ab8f`.
  Публичный ReadyStore и опубликованные теги в этом прогоне не менялись.
- Независимая команда `scripts.release.acceptance` с подписанным манифестом
  и неполной матрицей возвратила 1. Файл receipt отсутствует.

## Отдельные испытания отказов на Debian 13

- На отдельных tmpfs внутри mount namespace проверены нехватка байтов
  Docker, нехватка inode containerd, ФС данных и копий, а также исчерпание
  временного пространства после начатой записи. Проверка указала
  соответствующие точки монтирования. Исходное приложение вернуло HTTP
  200 с неизменным указателем релиза. Это проверка подсистемы, без
  повторения полного цикла обновления для каждой ФС.
- Реальный доверенный HTTPS listener сначала вернул 503, затем те же
  байты через повтор. Другой корень получил постоянную ошибку TLS.
  Независимый Compose с нездоровым контейнером остановлен на пределе
  ввода-вывода в 3 с, после чего тестовый проект удалён. Исходный HTTP
  и указатель релиза сохранились.
- Неиспользованный pairing code был предъявлен через защищённый мастер
  через 605,1 с и отвергнут HTTP 401.
