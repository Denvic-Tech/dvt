# Краткое ТЗ на мастер первой установки DVT

## Запуск на сервере

Пользователь запускает `install.sh`. Скрипт определяет адрес сервера, скачивает проверенный образ мастера и запускает мастер на порту 8888. Если порт занят, скрипт выбирает свободный. В интерактивной консоли появляются готовые одноразовые ссылки для локального и удалённого доступа с фактическим портом. Подтверждать адрес и путь в консоли не требуется.

До отправки формы мастер использует временный каталог для своих стартовых файлов. После отправки постоянные файлы экземпляра создаются непосредственно в каталоге, выбранном пользователем. Этот путь сохраняется для установки, последующих запусков и восстановления. После успешной инициализации временные файлы очищаются автоматически.

## Настройки

Оформление соответствует светлой теме DVT UI. На экране видны шесть настроек. Разделители между строками проходят на всю ширину карточки.

| Поле | Поведение |
| --- | --- |
| Адреса DVT | Предложить адрес сервера с `http://`. Поддержать редактирование, добавление кнопкой «+» и удаление крестиком. |
| Версия DVT | Выбор из доступных для установки версий каталога. |
| Путь установки | Абсолютный путь на сервере, по умолчанию `/var/lib/dvt`. |
| Порт приложения | От 1 до 65535, по умолчанию 80. |
| Число воркеров | Целое положительное число, по умолчанию 4. |
| Включить AI MCP | Переключатель, изначально выключен. |

По нажатию **Установить DVT** мастер открывает экран установки. Подготовка и применение запускаются автоматически. В штатном сценарии пользователю не нужно видеть ID операции, выбирать план или нажимать «Продолжить». При ошибке мастер сообщает, что нужно исправить.

## Ход и завершение установки

Слева — прокручиваемый журнал реальных событий со временем, копированием и скачиванием. Внизу журнал следует за новыми строками. При чтении предыдущих строк позиция сохраняется. Ползунок скруглён, у краёв дорожки есть отступ. Справа — обновляемые статусы подготовки, загрузки образов, настройки БД, запуска сервисов и проверки доступности. На узком экране статусы располагаются под журналом.

После успеха появляется кнопка **Открыть DVT** с однократной анимацией салюта и конфетти, как в [макете](prototype/index.html). При системном ограничении движения кнопка появляется сразу. Она открывает новую вкладку по первому адресу DVT с выбранным портом. Для новой установки открывается первичная настройка администратора.
