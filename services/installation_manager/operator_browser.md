# Установка и обновление через браузер

Для готовой версии на Debian 13 или Ubuntu 24.04 LTS запустите утверждённый
[bootstrap](customer_installation.md) с адресом DVT и защищённым каталогом.
В версии с прямым HTTP-доступом откройте в браузере ссылку `Manager` из
терминала. Фрагмент ссылки содержит одноразовый код для входа. Браузер убирает
его из адресной строки и открывает мастер. При повторном запуске установщик
печатает новую ссылку. HTTP передаёт данные открытым текстом. Для экземпляра,
установленного с локальным HTTPS, используйте адрес и способ доступа из его терминала.

Каталог по умолчанию загружает подписанные манифесты из настроенного Distribution
origin. Дополнительные HTTPS origin артефактов и DNS-адреса Registry задаются
администратором в `--release-catalog-config` полями `asset_origins` и
`registry_hosts`. Передайте CA загрузчика через `--release-catalog-ca`, если
каталог использует частный TLS CA. Docker проверяет TLS Registry по своей
конфигурации доверия.

## Первый администратор

1. Откройте ссылку из терминала. Выберите версию, адреса DVT и каталог на сервере.
   Предложенные значения — `/var/lib/dvt`, порт приложения 80 и четыре воркера.
   При необходимости включите AI MCP.
2. Нажмите **Установить DVT**. На одном экране появятся журнал и этапы установки.
   Строки журнала можно скопировать или скачать.
3. Нажмите **Открыть DVT**. Мастер откроет в новой вкладке первичную настройку
   по одноразовой ссылке. Создайте администратора и войдите в DVT.

## Обновление и восстановление

Суперадминистратор открывает **Профиль → Обновление DVT**, проверяет фактическую
версию и схему и выбирает допустимую цель. Если нужен промежуточный релиз,
интерфейс показывает всю цепочку и предлагает подготовить первый переход.
Подготовка фиксирует digest, проверяет доступ к комплекту, место и сервисы.
При проблемах Distribution мастер показывает ошибку и дату последнего
сохранённого каталога. Для уже проверенного офлайн-комплекта используйте
[офлайн-процедуру](release_catalog.md).

Перед **Применить обновление** проверьте план и откройте независимый HTTPS-адрес
мастера. В окне обслуживания DVT завершает принятые задания, отменяет
непринятые корневые запуски, пропускает новые запуски по расписанию и учитывает
ранее сохранённые повторы. Основной UI и мастер показывают одну операцию.
При перезапуске вкладка сохраняет ID и последнюю подтверждённую стадию.

Для отказов используйте доступное действие из журнала и скачайте диагностику
по ID. После восстановления данных отдельно подтвердите запуск в независимом
мастере. Этот запуск возможен только после проверки точки восстановления.
Данные после создания копии теряются, внешние эффекты не переписываются.
Подготовка копии на чистом хосте и аварийная процедура описаны в
[руководстве по восстановлению](recovery.md).
