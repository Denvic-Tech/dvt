# Python над DataFrame

Тип ноды: `DataFrameExecCode`.

## Назначение и выбор

Выполняет собственный Python над обязательным DataFrame, когда специализированных трансформаций недостаточно. Через MCP объясните причину в комментарии ноды.

## Входы и настройка

Подключите `df`; задайте `code` (по умолчанию `df_out = df_in`). Код видит `df_in`, `pd`, `dd`, `node`, `logger`, неизменяемые `input_variables` / `project_variables` и карту выходных переменных.

## Результат

Присвойте Dask DataFrame переменной `df_out`; он станет `output`. В отличие от ExecutePython, pandas DataFrame автоматически не принимается.

## Поведение и ограничения

Код выполняется с Python builtins внутри worker без песочницы. Операции Dask могут оставаться ленивыми; compute материализует данные. Нода не переопределяет базовый путь выполнения метаданных, поэтому код может выполняться при их получении. Избегайте внешних побочных эффектов в трансформациях.

## Примеры

С подключённым DataFrame этот пример контракта возвращает его без изменений. Для реальной задачи объясните, почему нужное преобразование не выражается встроенными нодами.

Значения параметров, без оболочки MCP patch:

```json
{
  "code": "df_out = df_in"
}
```

## Типовые ошибки

Отсутствие df_out или неверный тип результата вызывает ошибку. pandas-результат явно оберните через `dd.from_pandas`. Ошибки Python сообщаются как ошибки кода.
