# Сводная таблица

Тип ноды: `DataFramePivot`.

## Назначение и выбор

Агрегирует показатели длинного формата в широкую таблицу с колонкой для каждой категории.

## Входы и настройка

Подключите `df`; задайте `index` (ключ строки), `column` (ось категорий) и непустой `aggfunc`: показатель → `mean`, `sum`, `count`, `first` или `last`.

## Результат

В `output` выбранный ключ строки становится индексом. Значения категорий становятся именами колонок. Если несколько показателей создают одно имя, первый в `aggfunc` получает короткое имя, остальные — префикс показателя и при необходимости дополнительное уточнение.

## Поведение и ограничения

Повторяющиеся пары ключ/категория агрегируются. Ось категорий приводится к известным категориям, что может потребовать чтения данных. Высокая кардинальность создаёт очень широкую таблицу. Показатели должны быть обычными колонками. First/last отражают порядок данных, а не бизнес-правило последней записи по дате.

## Примеры

Строки `(A, jan, 10)` и `(A, jan, 5)` заданы в `region, month, amount`.

Значения параметров, без оболочки MCP patch:

```json
{
  "index": "region",
  "column": "month",
  "aggfunc": {
    "amount": "sum"
  }
}
```

В сводной таблице регион A имеет `jan=15`.

## Типовые ошибки

Пустая/неподдерживаемая агрегация запрещена. Если следующая нода не видит поле, проверьте фактические плоские имена и индекс. Перед pivot больших данных уменьшите кардинальность категорий.
