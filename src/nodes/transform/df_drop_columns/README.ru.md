# Удаление колонок

Тип ноды: `DataFrameDropColumns`.

## Назначение и выбор

Удаляет ненужные колонки DataFrame. Удобна, когда известны удаляемые поля; для явного списка оставляемых используйте `DataFrameSelectColumns`.

## Входы и настройка

Подайте DataFrame в `df`; задайте `columns` точными именами удаляемых колонок.

## Результат

`output` содержит оставшиеся колонки и строки.

## Поведение и ограничения

Отсутствующие имена игнорируются. Если удаляемая бизнес-колонка также задаёт имя физического индекса, индекс сохраняется под служебным именем DVT вместе с divisions. Удаляются поля, а не строки или дубли.

## Примеры

Вход `df` содержит `id, amount, debug`.

Значения параметров (без оболочки MCP patch):

```json
{
  "columns": [
    "debug"
  ]
}
```

Выход содержит `id, amount`.

## Типовые ошибки

Если результат не изменился, проверьте написание и регистр: отсутствующие имена не вызывают ошибку. Проверьте ссылки последующих нод на удалённые поля.
