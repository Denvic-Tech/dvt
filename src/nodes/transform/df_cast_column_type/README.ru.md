# Приведение типов колонок

Тип ноды: `DataFrameCastColumnType`.

## Назначение и выбор

Приводит типы выбранных колонок перед join, вычислениями или записью.

## Входы и настройка

Подключите `df`; задайте `dtypes`: колонка → целевой dtype, например `Int64`, `float64`, `string`, `datetime64[ns]`, `datetime64[ns, UTC]`.

## Результат

`output` сохраняет колонки со значениями, преобразованными в заданные типы.

## Поведение и ограничения

Преобразование в целое отбрасывает дробную часть к нулю, а не округляет. Некорректный числовой текст вызывает ошибку. Для пропусков используйте nullable integer dtype. Даты разбираются с UTC, неверные значения становятся NaT; целевой datetime без пояса удаляет пояс после нормализации в UTC, а тип с поясом переводит в него. Остальные типы используют обычный `astype`. Ошибки ленивых вычислений могут проявиться только при расчёте.

## Примеры

Числовые `qty` равны `2.9, -2.9, null`.

Значения параметров (без оболочки MCP patch):

```json
{
  "dtypes": {
    "qty": "Int64"
  }
}
```

Значения становятся `2, -2, null` в nullable целочисленном типе.

## Типовые ошибки

Ошибка преобразования: проверьте неверные значения и диапазон типа. Сдвиг даты: проверьте исходные смещения и нормализацию UTC. Приведение к Boolean не разбирает произвольные бизнес-строки.
