# Преобразование в длинный формат

Тип ноды: `DataFrameUnpivot`.

## Назначение и выбор

Превращает несколько колонок показателей в строки имя/значение. Для обратного представления используйте `DataFramePivot`.

## Входы и настройка

Подключите `df`. `index_columns` задаёт сохраняемые идентификаторы; `columns_to_long` — колонки показателей, либо опустите его для всех остальных полей. Имена результата по умолчанию `variable` и `value` задаются через `new_column_name_with_names` и `new_column_name_with_values`.

## Результат

`output` повторяет идентификаторы для каждого развёрнутого поля и добавляет колонки имени/значения.

## Поведение и ограничения

Обе новые колонки преобразуются в строки для ненулевых значений, пропуски — в None. Числовые типы показателей не сохраняются. Идентификаторы, существующие только в именованном индексе, переводятся в колонки. Число строк растёт с числом разворачиваемых полей.

## Примеры

Во входе одна строка `id=1, jan=10, feb=20`.

Значения параметров, без оболочки MCP patch:

```json
{
  "index_columns": [
    "id"
  ],
  "columns_to_long": [
    "jan",
    "feb"
  ]
}
```

Выход имеет две строки: `(1, jan, "10")` и `(1, feb, "20")`.

## Типовые ошибки

Нет поля: проверьте метаданные. Конфликт имён: выберите свободные имена результата. Для числовой агрегации приведите колонку значения после unpivot.
