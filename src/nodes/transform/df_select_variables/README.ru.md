# Переменные из DataFrame

Тип ноды: `DataFrameSelectVariables`.

## Назначение и выбор

Агрегирует колонки DataFrame в именованные скалярные переменные. Если результат нужен таблицей, используйте `DataFrameGroupByAgg`.

## Входы и настройка

Подключите `df`; `selected_variables` сопоставляет имя переменной с `source_column_name` и `agg_func`. Функции: `first`, `last`, `min`, `max`, `sum`, `mean`, `count`, `nunique`, `std`, `var`. Словарь по умолчанию пуст.

## Результат

`output_variables` содержит пользовательские переменные с выведенными типами. Выходного порта DataFrame нет.

## Поведение и ограничения

Полное выполнение вычисляет скалярные агрегаты; одинаковая пара колонка/функция рассчитывается один раз за вызов. Пропуски становятся None. First использует Dask head, last — tail, поэтому важны граничные партиции и текущий порядок. Режим метаданных выдаёт невычисленные типизированные переменные без расчёта агрегатов. Кеширование выполнения этой ноды отключено.

## Примеры

`df.amount` содержит `10, 20`.

Значения параметров, без оболочки MCP patch:

```json
{
  "selected_variables": {
    "total": {
      "source_column_name": "amount",
      "agg_func": "sum"
    }
  }
}
```

Переменная `total` равна 30 и может поступать в `input_variables` следующих нод.

## Типовые ошибки

Отсутствующая колонка или неверная конфигурация запрещены. Пустой словарь не создаёт новых переменных. Не используйте first/last как хронологический минимум/максимум; выберите min/max или обеспечьте порядок.
