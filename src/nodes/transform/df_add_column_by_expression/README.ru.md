# Добавление и изменение колонок выражениями

Экспериментальная нода `DataFrameAddColumnByExpression`.

Прежние входы `df`, `column_name`, `expression` по-прежнему рассчитывают одно
поле. Выражения используют pandas/Dask eval, а не произвольные инструкции Python.

Для независимых новых полей задайте `calculated_columns`:
```json
{"calculated_columns": [{"name": "total", "expression": "price * quantity"}, {"name": "discounted", "expression": "price * 0.9"}]}
```
Все выражения читают исходную таблицу. Ссылки на только что рассчитанные поля,
повторные имена результатов и конфликты с исходными колонками запрещены.

Для выбранных полей используйте `column_rules` по контракту
[Regex Replace](../df_regex_replace/README.ru.md#обработка-нескольких-колонок),
с `params: {"expression": "__column__ * 2"}`.
Зарезервированный токен `__column__` означает текущую исходную колонку и не
заменяется внутри строковых литералов. Действует первое подходящее включённое
правило. Для сохранения источников задайте `output.mode=new` и суффикс или
соответствие имён. `calculated_columns` и `column_rules` несовместимы.

UI предлагает два сценария: преобразовать колонки или рассчитать новые.
Редактор выражений подсказывает имена колонок; дополнительные настройки и
предпросмотр схемы находятся под «Дополнительно». Вычисление ленивое,
индекс строк сохраняется.

## Переход сохранённых графов

Миграция БД `0063` автоматически переводит существующие ноды на новый контракт.
Исходное выражение и имя результата переносятся в `calculated_columns` без
подстановки `__column__`. Существующее разрешение перезаписи сохраняется через
`overwrite_existing: true`.
`input_bindings` сохраняет параметры из выражений и подключений: они вычисляются
при каждом запуске через исходные входы. Редактирование соответствующего поля в UI
заменяет только его привязку явным значением. Другие привязки сохраняются.

Старые входы и служебные данные миграции остаются для обратимого отката. Повторный
upgrade не перезаписывает настроенный контракт. Downgrade восстанавливает исходную
запись, если контракт не редактировался; при наличии правок сохраняет новые данные,
а предыдущая версия использует оставленные старые входы.
