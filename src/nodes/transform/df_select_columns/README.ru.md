# Выбор колонок

Тип ноды: `DataFrameSelectColumns`.

## Назначение и выбор

Оставляет выбранные обычные колонки. Если известны только лишние поля, используйте `DataFrameDropColumns`.

## Входы и настройка

Подключите `df` и передайте непустой список `columns` в нужном порядке.

## Результат

`output` содержит оставленные колонки с исходным индексом.

## Поведение и ограничения

Реализация молча отбрасывает отсутствующие имена и выбранное имя, совпадающее с именем индекса, даже если оно есть и среди колонок. Физический индекс сохраняется. При пустом исходном списке выполнение выходит до присвоения `output`; это не сокращение для всех колонок. Если все запрошенные имена отфильтрованы, результат может не иметь обычных колонок.

## Примеры

Во входе есть `id, amount, region` и безымянный индекс.

Значения параметров (без оболочки MCP patch):

```json
{
  "columns": [
    "amount",
    "region"
  ]
}
```

Обычные выходные колонки — `amount, region` в указанном порядке.

## Типовые ошибки

Нет результата: не передавайте пустой список. Пропало поле: проверьте и колонки входа, и имя индекса. Перед настройкой потребителя перечитайте выходные метаданные.
