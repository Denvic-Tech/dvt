# Разбиение колонки

Тип ноды: `DataFrameSplitColumn`.

## Назначение и выбор

Разбивает текстовую колонку на фиксированное число новых колонок.

## Входы и настройка

Подключите `df`; выберите `column` и `delimiter`. `max_splits=1` создаёт два поля; в общем случае их `max_splits + 1`. `drop_source=false` сохраняет оригинал.

## Результат

`output` добавляет `<column>_1`, `<column>_2` и далее, сохраняя или удаляя источник согласно настройке.

## Поведение и ограничения

Каждая партиция разбивается после приведения источника к строке. Недостающие части заполняются NaN. Null также проходит строковое преобразование. Разделитель использует поведение pandas `str.split` по умолчанию; многосимвольные шаблоны могут трактоваться как regex. Конфликты с существующими именами результата не разрешаются.

## Примеры

Входное `code` равно `A-42-X`.

Значения параметров (без оболочки MCP patch):

```json
{
  "column": "code",
  "delimiter": "-",
  "max_splits": 1,
  "drop_source": false
}
```

`code_1=A`, `code_2=42-X`; `code` сохраняется.

## Типовые ошибки

Неверные места разбиения: проверьте смысл delimiter/regex. Недостающие части допустимы. Переименуйте уже существующие поля `<column>_N` перед разбиением.
