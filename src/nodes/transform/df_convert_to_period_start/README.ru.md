# Начало периода

Тип ноды: `DataFrameConvertToPeriodStart`.

## Назначение и выбор

Вычисляет начало календарного периода для группировки или отчётности. Изменяет даты без агрегации строк.

## Входы и настройка

Подключите `df`; задайте `column`. `period` по умолчанию `month`; также доступны `week`, `year`, `day`, `hour`, `minute`, `second`. Необязательный `new_column` сохраняет источник; иначе он перезаписывается.

## Результат

`output` содержит колонку начала периода и остальные исходные поля.

## Поведение и ограничения

Значения другого типа разбираются как даты; неверные становятся NaT. Неделя начинается в понедельник. Месяц/год используют календарное начало. У результата удаляется часовой пояс с сохранением рассчитанного местного времени. Нода не сортирует и не группирует данные.

## Примеры

`created_at` равно `2026-09-23 14:20:00`.

Значения параметров, без оболочки MCP patch:

```json
{
  "column": "created_at",
  "period": "month",
  "new_column": "month"
}
```

`month` равно `2026-09-01 00:00:00`; при необходимости далее агрегируйте через `DataFrameGroupByAgg`.

## Типовые ошибки

Неожиданный NaT: проверьте разбор дат и переходы времени. Неверная граница отчёта: задайте нужный пояс до расчёта периода. Для сохранения исходной даты задайте новую колонку.
