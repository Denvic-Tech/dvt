# Группировка и агрегация

Тип ноды: `DataFrameGroupByAgg`.

## Назначение и выбор

Группирует строки и вычисляет именованные агрегаты либо агрегирует весь DataFrame.

## Входы и настройка

Подключите `df`. `group_by_columns=[]` задаёт глобальную агрегацию. Передайте `new_cols`, `source_cols`, `agg_funcs` вместе списками одинаковой длины либо опустите все три для уникальных ключей групп. `dropna=false` сохраняет группы с null-ключами. Функции: `sum`, `mean`, `min`, `max`, `count`, `first`, `last`, `nunique`, `std`, `var`.

## Результат

`output` содержит ключи групп и именованные результаты; глобальная агрегация даёт одну строку. При ключах без агрегатов результат содержит уникальные комбинации ключей.

## Поведение и ограничения

Фильтрацией null-ключей управляет `dropna`, а не заполнение исходных значений. Индексы безопасно сбрасываются при группировке и формировании результата; проверяйте выходные метаданные. Порядок не гарантируется. First/last зависят от существующего порядка; глобальные first/last пропускают null при обходе партиций. Полностью пустые настройки группировки и агрегации недопустимы.

## Примеры

Строки `(EU,10)` и `(EU,20)` используют `region, amount`.

Значения параметров, без оболочки MCP patch:

```json
{
  "group_by_columns": [
    "region"
  ],
  "source_cols": [
    "amount"
  ],
  "agg_funcs": [
    "sum"
  ],
  "new_cols": [
    "total"
  ],
  "dropna": false
}
```

Выход содержит регион EU с `total=30`. Для одного итога по всем регионам задайте `group_by_columns=[]` с теми же списками агрегации.

## Типовые ошибки

Разные длины или частично заполненные списки агрегации запрещены. Проверьте числовые типы для арифметики и уникальность имён результата. Перед first/last определите явное бизнес-правило.
