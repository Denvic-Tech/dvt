# Объединение строк

Тип ноды: `DataFrameUnion`.

## Назначение и выбор

Добавляет строки двух DataFrame. Для сопоставления ключей и объединения колонок используйте `DataFrameJoin`.

## Входы и настройка

Подключите `df1` и `df2`. `column_mapping` сопоставляет целевое/левое имя правому: `{"id":"external_id"}` переименует `df2.external_id` в `id`. При совпадении имён используйте `{}`.

## Результат

`output` объединяет строки обоих входов. Несопоставленные колонки сохраняются с пропусками для другой ветки; дубли строк остаются.

## Поведение и ограничения

Полезные индексы сбрасываются с безопасными именами. Некорректные/отсутствующие правые поля mapping пропускаются; повторные итоговые имена запрещены. Общие datetime-колонки нормализуются через UTC в даты без пояса с наносекундной точностью. Другие несовместимые типы могут расширяться. Дедупликации или бизнес-сортировки нет.

## Примеры

В `df1` есть `id=1, amount=10`; в `df2` — `external_id=2, amount=20`.

Значения параметров, без оболочки MCP patch:

```json
{
  "column_mapping": {
    "id": "external_id"
  }
}
```

Результат содержит обе строки в колонках `id, amount`.

## Типовые ошибки

Лишние колонки: проверьте направление mapping и имена. Ошибка повторных имён: обеспечьте уникальность правой схемы после переименования. До объединения сопоставьте типы и смысл полей.
