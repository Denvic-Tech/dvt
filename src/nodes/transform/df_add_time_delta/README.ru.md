# Смещение даты

Тип ноды: `AddTimeDeltaToDataFrame`.

## Назначение и выбор

Добавляет календарное смещение к колонке даты, например для расчёта срока оплаты.

## Входы и настройка

Подключите `df`; задайте `column_with_time` и `new_column_with_time`. `years`, `months`, `days`, `hours`, `minutes`, `seconds` по умолчанию 0. Схема также содержит `weeks`, `milliseconds`, `microseconds`, но текущая реализация их не использует.

## Результат

`output` содержит исходный DataFrame с добавленной или перезаписанной целевой колонкой.

## Поведение и ограничения

Используются календарные правила pandas DateOffset. Реализованные компоненты приводятся через `int`, поэтому дробная часть отбрасывается. Валидация принимает datetime/timedelta, но поддержка смещения зависит от базовой операции; для календарных смещений используйте datetime. Строки сначала приведите к дате.

## Примеры

`created_at` имеет тип datetime и значение `2026-01-10 12:00:00`.

Значения параметров, без оболочки MCP patch:

```json
{
  "column_with_time": "created_at",
  "new_column_with_time": "due_at",
  "days": 7
}
```

`due_at` становится `2026-01-17 12:00:00`.

## Типовые ошибки

Нет изменения от недель/долей секунды: эти поля пока не используются; целые недели задавайте днями. Ошибка типа: приведите источник к datetime. Проверьте имя результата, чтобы не перезаписать нужные данные.
