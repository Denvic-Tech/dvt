# Переменные в DataFrame

Тип ноды: `ConvertVariablesToDataFrame`.

## Назначение и выбор

Преобразует карту переменных в одну строку DataFrame. Подходит для сохранения или объединения значений уровня выполнения.

## Входы и настройка

Соедините upstream `output_variables` → `input_variables`. Вход — непустая карта типизированных переменных. Специальных скалярных параметров настройки нет.

## Результат

`output` — DataFrame из одной партиции с колонкой на каждую переменную и одной строкой при полном выполнении.

## Поведение и ограничения

Скалярные типы преобразуются в pandas dtypes; списки и JSON остаются object-ячейками, а не отдельными строками. Режим метаданных создаёт те же колонки без строк. При полном выполнении невычисленные значения запрещены.

## Примеры

Создайте переменные `region` (STRING, `EU`) и `count` (INT, 3), затем подключите их выходы переменных.

Значения параметров, без оболочки MCP patch:

```json
{}
```

Результат — одна строка `region=EU, count=3`. Пустая настройка намеренна: значения поступают по рёбрам.

## Типовые ошибки

Пустой вход: подключите источники переменных. Неверный payload: используйте типизированные выходы переменных, а не обычный словарь значений. Вычислите зависимости до полного выполнения.
