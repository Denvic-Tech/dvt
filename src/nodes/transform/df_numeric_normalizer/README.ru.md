# Ограничение числового диапазона

Тип ноды: `DataFrameNumericNormalizer`.

## Назначение и выбор

Ограничивает числовые значения границами. Несмотря на имя, нода не масштабирует распределение значений.

## Входы и настройка

Подключите `df`. `columns_to_normalize` выбирает поля; отсутствие/пустой список означает все кандидаты. Явно задайте `lower_border` и `upper_border`: обе границы по умолчанию 0. `replace_empty_values=true` заполняет null нижней границей.

## Результат

`output` сохраняет все колонки; выбранные целочисленные/вещественные поля ограничиваются диапазоном.

## Поведение и ограничения

Значения вне диапазона заменяются ближайшей границей. Нечисловые поля и отсутствующие выбранные имена пропускаются; отсутствие подходящих числовых колонок — ошибка. Timedelta и complex не обрабатываются. Равные границы допустимы и превращают ненулевые числа в константу.

## Примеры

`score` содержит `-5, 50, 120, null`.

Значения параметров (без оболочки MCP patch):

```json
{
  "columns_to_normalize": [
    "score"
  ],
  "lower_border": 0,
  "upper_border": 100,
  "replace_empty_values": true
}
```

Результат — `0, 50, 100, 0`.

## Типовые ошибки

Все значения стали нулевыми: проверьте верхнюю границу по умолчанию. Нижняя граница больше верхней запрещена. Строки с числами нужно предварительно привести к числовому типу.
