# Объединение DataFrame

## Назначение и выбор

`DataFrameJoin` объединяет колонки двух DataFrame по совпадающим ключам. Подходит для обогащения фактов справочником. Для добавления строк используйте `DataFrameUnion`.

## Входы и настройка

Подайте DataFrame по рёбрам в `left` и `right`. Задайте `left_on` и `right_on` списками точных имён колонок одинаковой длины. `how` по умолчанию `left`; другие режимы: `right`, `outer`, `inner`, `cross`. Хотя схема допускает отсутствие ключей, для обычного соединения задавайте их явно. `cross` не использует ключи.

## Результат

`output` — DataFrame с объединёнными колонками. Совпадающие имена неключевых колонок справа получают суффикс `_right`; имена слева сохраняются. Служебные колонки DVT удаляются.

## Поведение и ограничения

Явно заданный ключ берётся из обычной колонки, если она есть. Именованный бизнес-индекс может служить ключом, если одноимённой колонки нет. Подтверждённый диапазонный индекс DBV3 может ускорить соединение по одному общему ключу при известных границах партиций. Общий ключ сохраняется как колонка. Повторяющиеся ключи дают все совпадающие комбинации. Null обрабатываются по правилам merge, порядок строк не задан. Cross join строит декартово произведение, а конфликтующие имена с суффиксом `_right` могут потребовать предварительного переименования.

## Примеры

Связи: продажи → `left`, клиенты → `right`. В продажах есть `customer_id=7, amount=100`, в клиентах — одна строка `id=7, name="Ada"`.

```json
{"left_on":["customer_id"],"right_on":["id"],"how":"left"}
```

Это значения параметров, а не MCP patch графа. Выходная строка содержит оба ключа, `amount=100` и `name="Ada"`. Продажа без совпадения сохраняется с null в полях клиента.

## Типовые ошибки

Лишние строки: проверьте повторяющиеся комбинации ключей с обеих сторон. Нет ключа или несовместимы типы: проверьте метаданные и нормализуйте имена/типы. Конфликт имён после добавления суффикса: переименуйте колонки до соединения. Для повторов в справочнике определите бизнес-правило, а не удаляйте их произвольно.
