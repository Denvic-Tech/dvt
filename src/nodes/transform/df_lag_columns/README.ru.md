# Сдвиг значений колонок

Тип ноды: `DataFrameLagColumns`.

## Назначение и выбор

Добавляет сдвинутые копии колонок для сравнения с предыдущими/следующими строками.

## Входы и настройка

Подключите `df`; задайте `columns_to_lag` и ненулевой `lag_steps`. Положительный сдвигает вниз, отрицательный — вверх. `fill_value` по умолчанию null (пропуски сохраняются).

## Результат

`output` добавляет `<column>_lagN` для положительного сдвига или `<column>_lag-N` для отрицательного.

## Поведение и ограничения

Сдвиг следует текущему порядку строк без сортировки или группировки по сущности. Заданное заполнение заменяет все null в сдвинутом столбце, включая исходные. Реализация пытается восстановить исходный dtype; null могут вызвать ошибку целочисленного приведения позже при ленивом расчёте. Большие сдвиги ограничены размером партиций Dask.

## Примеры

Упорядоченный вход из одной партиции имеет `amount=10, 20, 30`.

Значения параметров (без оболочки MCP patch):

```json
{
  "columns_to_lag": [
    "amount"
  ],
  "lag_steps": 1,
  "fill_value": 0
}
```

`amount_lag1` равен `0, 10, 20`; исходные значения сохраняются.

## Типовые ошибки

Нулевой сдвиг запрещён. Проверьте каждую запрошенную колонку: выполнение обращается ко всем именам. Обеспечьте порядок и совместимость fill_value с типом.
