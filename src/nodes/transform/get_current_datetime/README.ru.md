# Текущее время

Тип ноды: `GetCurrentDateTime`.

## Назначение и выбор

Добавляет время выполнения в каждую строку, например для аудита загрузки.

## Входы и настройка

Подключите DataFrame в `df` и задайте `column_name`. Отдельного параметра часового пояса нет.

## Результат

`output` содержит вход и именованную колонку времени с UTC; существующая колонка с таким именем перезаписывается.

## Поведение и ограничения

Одна отметка времени фиксируется при вызове `process` и назначается всем строкам, а не вычисляется для каждой отдельно. Кешированный результат может сохранить прежнее время; для новой отметки нужно фактическое выполнение. Пустой вход не создаёт строк.

## Примеры

Подключите DataFrame с двумя строками.

Значения параметров, без оболочки MCP patch:

```json
{
  "column_name": "loaded_at"
}
```

Обе строки получают одинаковое UTC-значение `loaded_at` этого выполнения.

## Типовые ошибки

Старое время: проверьте выполнение/использование кеша. Перезаписалось поле: выберите свободное имя. Для представления в другом поясе добавьте преобразование далее.
