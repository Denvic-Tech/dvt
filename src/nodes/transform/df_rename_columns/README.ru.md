# Переименование колонок

Тип ноды: `DataFrameRenameColumns`.

## Назначение и выбор

Переименовывает поля без изменения значений. Используйте перед join или записью для согласования имён.

## Входы и настройка

Подключите `df`; задайте `mapping` объектом пар старое имя → новое имя. По умолчанию null.

## Результат

`output` содержит переименованные колонки; остальные поля и строки сохраняются.

## Поведение и ограничения

При null в mapping возвращается исходный DataFrame. Совпавшее имя индекса также переименовывается с сохранением физического индекса. Отсутствующая колонка не создаётся. Повторяющиеся целевые имена автоматически не разрешаются.

## Примеры

Подайте DataFrame с `customer_id, amount`.

Значения параметров (без оболочки MCP patch):

```json
{
  "mapping": {
    "customer_id": "id"
  }
}
```

Выходные поля — `id, amount`.

## Типовые ошибки

Если имя не изменилось, проверьте исходное написание. Выбирайте уникальные целевые имена и обновляйте настройки ключей/колонок следующих нод.
