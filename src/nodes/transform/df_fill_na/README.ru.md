# Заполнение пропусков

Тип ноды: `DataFrameFillNA`.

## Назначение и выбор

Заполняет пропуски статистикой или распространением соседних значений. Словарь этой ноды содержит названия функций, а не литеральные значения замены.

## Входы и настройка

Подключите `df`; передайте непустой `fill_values`: колонка → `mean`, `median`, `mode`, `min`, `max`, `ffill` или `bfill`.

## Результат

`output` сохраняет колонки и заполняет пропуски в настроенных полях.

## Поведение и ограничения

Статистика вычисляется по выбранному столбцу; `mode` выбирает значение с максимальной частотой. Для равных частот отдельного бизнес-правила нет. Направленное заполнение зависит от порядка строк/партиций; нода не сортирует и не группирует данные. Полностью пустая колонка может остаться пустой или не дать статистику. Поддержка операции зависит от Dask и типа данных.

## Примеры

Числовой вход `amount` содержит `10, null, 20`.

Значения параметров (без оболочки MCP patch):

```json
{
  "fill_values": {
    "amount": "mean"
  }
}
```

Пропуск заменяется на 15.

## Типовые ошибки

Валидация отклоняет пустой словарь, неизвестные колонки и функции. Если статистика не подходит типу, сначала очистите/приведите данные. Перед ffill/bfill обеспечьте осмысленный порядок.
