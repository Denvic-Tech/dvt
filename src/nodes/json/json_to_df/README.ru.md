# JSON в DataFrame

Тип ноды: `JsonToDataFrame`.

## Назначение и выбор

Создаёт DataFrame из JSON-записей. Вложенные документы сначала нормализуйте через `JSONEditor`.

## Входы и настройка

Подайте разобранный JSON в `json`, предпочтительно список объектов-строк. Один словарь превращается в список из одной строки. `orient` объявлен с default `columns`, но текущая реализация его не использует.

## Результат

`output` — Dask DataFrame, построенный из материализованного pandas DataFrame.

## Поведение и ограничения

После оборачивания словаря используется `pd.DataFrame(json)`; JSON-строка не разбирается, вложенные объекты не разворачиваются, форматы columns/index/tight не интерпретируются. Число партиций — `max(1, len(json) // 100000)`. До партиционирования весь вход находится в памяти.

## Примеры

Соедините JSON `[{"id":1,"amount":10},{"id":2,"amount":20}]` → `json`. Выход имеет две строки и колонки `id, amount`.

Значения параметров, без оболочки MCP patch:

```json
{
  "orient": "columns"
}
```

## Типовые ошибки

Неожиданная одна строка с вложениями: подайте записи вместо словаря по колонкам. Строковый вход: разберите его ранее. Смешанные типы: нормализуйте записи и приведите типы далее.
