# Разворачивание JSON

Тип ноды: `ExpandJSON`.

## Назначение и выбор

Уплощает вложенные объекты и автоматически разворачивает массивы в комбинации записей. Для явного выбора путей разворачивания предпочтителен `JSONEditor`.

## Входы и настройка

Подайте разобранные данные в `json`: объект или список записей. Defaults: `separator="."`, `max_depth=15`, `max_array_size=100`, `max_total_rows=10000`.

## Результат

`output` — список плоских словарей с общим набором ключей, согласованно отсортированных и дополненных null для отсутствующих полей.

## Поведение и ограничения

Независимые массивы дают декартово произведение, а не попарное соединение элементов. Большие массивы могут обрезаться; при превышении бюджета строк записи массивы сохраняются вместо разворачивания. `max_total_rows` применяется отдельно к каждой верхнеуровневой записи, а не глобально. `max_depth` сейчас ограничивает анализ структуры и предупреждения, но не саму рекурсию уплощения. Пустые массивы становятся null. Если лимиты важны, проверяйте логи.

## Примеры

Вход `{"id":1,"tags":["a","b"]}` даёт две записи с `tags=a` и `tags=b`, обе с `id=1`.

Значения параметров, без оболочки MCP patch:

```json
{
  "separator": ".",
  "max_array_size": 100,
  "max_total_rows": 10000
}
```

## Типовые ошибки

Неожиданный рост строк: проверьте независимые массивы. Остались массивы или потерян хвост: проверьте предупреждения лимитов. Для управляемого общего лимита и явных explode-путей используйте JSONEditor.
