# DataFrame в JSON

Тип ноды: `DataFrameToJson`.

## Назначение и выбор

Преобразует небольшой DataFrame в JSON в памяти для API или обработки JSON.

## Входы и настройка

Подключите `df`. `orient`: `columns` (по умолчанию), `index` или `tight`.

## Результат

`output` — разобранный JSON, не строка и не путь файла. Columns отображает колонка → индекс → значение; index — индекс → колонка → значение; tight содержит index, columns, data и имена осей.

## Поведение и ограничения

Весь DataFrame вычисляется в pandas в памяти. Columns/index используют JSON-кодирование с ISO-датами и JSON null; tight нормализуется общим JSON-safe преобразователем. Повторяющиеся метки осей могут быть несовместимы с выбранным форматом. Массив records не формируется.

## Примеры

Одна строка `df` с индексом 0 и `id=7` даёт `{"id":{"0":7}}`.

Значения параметров, без оболочки MCP patch:

```json
{
  "orient": "columns"
}
```

## Типовые ошибки

Нехватка памяти: уменьшите вход перед преобразованием. Неверная форма JSON: выберите ориентацию. Не предполагайте, что `JsonToDataFrame` обращает каждый формат: текущая реализация строит DataFrame напрямую из записей.
