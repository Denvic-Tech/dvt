# Подготовка JSON

Тип ноды: `JSONEditor`.

## Назначение и выбор

Выбирает записи, уплощает объекты и выборочно разворачивает массивы перед `JsonToDataFrame`. Также нормализует распознанные табличные JSON-матрицы.

## Входы и настройка

Подключите `json`. Для предсказуемого выбора задайте `record_path`; иначе `auto_detect_record_path=true` может выбрать уверенного кандидата. `meta_paths` копирует поля в каждую строку; `explode_paths` разворачивает массивы; `keep_json_paths` сохраняет поддеревья; `exclude_paths` удаляет их. Пути с `$` абсолютны, остальные пути настройки относительны к записи. Defaults: `separator="."`, `max_rows=10000` (до 100000).

## Результат

`output` — список словарей-строк; сохранённый JSON и неразвёрнутые массивы остаются вложенными значениями.

## Поведение и ограничения

Исключение имеет приоритет над сохранением и разворачиванием. Сохранённые поддеревья не разворачиваются. Несколько explode-массивов перемножают комбинации. Пустой explode-массив даёт null-поле. `max_rows` обрезает весь результат с предупреждением. Отсутствующий record_path возвращает пустой список с предупреждением, а не ошибку. Режим метаданных тоже обрабатывает JSON. Meta-значения добавляются после уплощения и могут перезаписать совпадающие ключи.

## Примеры

Вход `{"batch":"B1","items":[{"id":1},{"id":2}]}` → `json` даёт строки `{id:1,batch:B1}` и `{id:2,batch:B1}`.

Значения параметров, без оболочки MCP patch:

```json
{
  "record_path": "$.items",
  "meta_paths": [
    "$.batch"
  ],
  "auto_detect_record_path": false
}
```

## Типовые ошибки

Пустой результат: проверьте фактический record_path и логи. Повторы строк: проверьте комбинации explode. Обрезанный результат не является полной выгрузкой; настройте лимит или осмысленно разделите вход.
