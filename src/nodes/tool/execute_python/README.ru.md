# Выполнение Python

Тип ноды: `ExecutePython`.

## Назначение и выбор

Выполняет собственный Python с необязательными DataFrame/JSON-входами, когда специализированных нод недостаточно. Объясните выбор в комментарии MCP-ноды.

## Входы и настройка

Задайте непустой `code`. Необязательные рёбра подают `df_in` и `json_in`. Код видит `pd`, `dd`, `node`, `logger`, неизменяемые входные/проектные переменные и изменяемые `output_variables`. Присваивайте `df_out` и/или `json_out`.

## Результат

`output` получает df_out (pandas преобразуется в Dask с одной партицией); `output_json` получает JSON-safe json_out; `signal_out` активируется при успехе. Незаданные выходы данных остаются None.

## Поведение и ограничения

В worker используются полные Python builtins без изолированной песочницы. Режим метаданных не запускает код: выдаёт пустую схему DataFrame, пустой JSON и активный сигнал. Поэтому произвольную runtime-схему нельзя подтвердить одними метаданными. Compute и большие JSON-результаты используют память worker; внешние эффекты требуют учёта повторных запусков.

## Примеры

Минимальный пример контракта выдаёт `{"ok":true}` в `output_json` и активирует `signal_out`. Рёбра данных не требуются.

Значения параметров, без оболочки MCP patch:

```json
{
  "code": "json_out = {'ok': True}"
}
```

## Типовые ошибки

Пустой код, неподдерживаемый df_out или несовместимый с JSON json_out запрещены. Успешные метаданные не проверяют Python-выполнение; запустите нужную цель и проверьте ошибки.
