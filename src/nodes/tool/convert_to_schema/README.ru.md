# Создание объекта схемы

Тип ноды: `ConvertToSchema`.

## Назначение и выбор

Создаёт TableSchema из DataFrame с описаниями колонок. Строки входа трактуются как записи схемы; это не простое отражение колонок самого входного DataFrame.

## Входы и настройка

Подключите таблицу описаний в `df`. `column_names` — имя её колонки с целевыми именами полей. Необязательные mapping-поля указывают колонки описаний dtypes, descriptions, nullable, defaults, order, primary_key, unique, precision, scale, length, format; `metadata_columns` сохраняет дополнительные атрибуты.

## Результат

`schema` — объект TableSchema для потребителей вроде `SchemaPolicy.schema`. Это не DataFrame и не DataFrameMetadata.

## Поведение и ограничения

Полное выполнение материализует/проверяет описания через builder каталога данных. Режим метаданных выдаёт пустой TableSchema без чтения строк; поля, заданные данными, доступны при полном выполнении. Преобразование не создаёт таблицу БД и не приводит бизнес-данные.

## Примеры

Подключите описания `field=id,dtype=INT` и `field=name,dtype=STRING`. Выходная схема описывает id и name. Отдельный бизнес-DataFrame затем можно проверить через SchemaPolicy.

Значения параметров, без оболочки MCP patch:

```json
{
  "column_names": "field",
  "column_dtypes": "dtype"
}
```

## Типовые ошибки

Неверные имена схемы: значения mapping называют колонки описаний, а не желаемые выходные поля. Некорректные/повторные записи: исправьте описания. Не подключайте этот TableSchema напрямую в CreateTable.dataframe_metadata.
