# Текстовая заметка

Тип ноды: `Text`.

## Назначение и выбор

Размещает поясняющий текст на графе для заголовков разделов или контекста читателя.

## Входы и настройка

Задайте `text_content`; оформление: `font_family`, `font_size` (8–72, default 14), `font_weight`, `font_style`, `text_color`, `background_color`, `border_width`, `border_color`, `text_align`. Defaults: Arial, normal, выравнивание слева, чёрный текст и прозрачный фон.

## Результат

Визуальный виджет; результата с бизнес-данными не создаёт.

## Поведение и ограничения

Метод process пуст. Текст и оформление поясняют граф, но не задают зависимости выполнения, не фильтруют данные и не передают значения переменных.

## Примеры

Разместите виджет рядом с соответствующими нодами. На графе появится подпись; данные pipeline не меняются.

Значения параметров, без оболочки MCP patch:

```json
{
  "text_content": "Orders → validation → warehouse",
  "font_size": 18,
  "font_weight": "bold"
}
```

## Типовые ошибки

Нет вычислений: используйте вычислительную ноду вместо виджета. Неверное оформление: проверьте допустимые enum и числовые границы текущего определения.
