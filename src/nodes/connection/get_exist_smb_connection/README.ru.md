# Соединение с SMB

Тип ноды: `GetExistSMBConnection`.

## Назначение и выбор

Получает сохранённое соединение SMB для следующих нод. Нода использует существующую настройку, не создаёт соединение и не извлекает бизнес-данные.

## Входы и настройка

Задайте `connection_id` доступным сохранённым соединением соответствующего вида. Через MCP используйте `connection_ref` из каталога соединений и актуальную схему значения входа; не передавайте credentials в граф.

## Результат

`connection` — объектный порт SMB_CONNECTION. Подключите его к входу `connection` потребителя; один источник может питать несколько нод.

## Поведение и ограничения

При получении проверяются доступ выполняющего пользователя и вид соединения. Кеширование выполнения ноды отключено. Сохранённое соединение должно иметь тип smbprotocol. Пути разрешаются внутри настроенного share; метаданные могут обращаться к нему. Для SMB не поддерживаются connection_overrides.

## Примеры

GetExistSMBConnection.connection → LoadExcel.connection. Настройте эту ноду доступной ссылкой из каталога:

```json
{"connection_id":"<connection_ref>"}
```

Это эскиз значения параметра; замените placeholder и используйте оболочку входа MCP при создании patch. Потребитель получает объект, а не эту строку.

## Типовые ошибки

Не найдено/нет доступа: проверьте соединения, доступные текущему пользователю/токену. Неверный вид: выберите соответствующую ноду соединения. Получение записи каталога не доказывает успешность последующего сетевого обращения или записи.
