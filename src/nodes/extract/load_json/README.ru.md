# Чтение JSON

Тип ноды: `LoadJSON`.

## Назначение и выбор

Читает целые JSON-документы из хранилища. Для табличной обработки далее используйте `JsonToDataFrame`.

## Входы и настройка

Подайте объект S3, FTP/SFTP или SMB из выхода `connection` соответствующей ноды во вход `connection`. `path` задаётся относительно bucket/prefix, начального каталога или share; не дублируйте корень и не передавайте credentials. Необязательный `connection_overrides` поддерживает bucket/prefix/verify S3 и начальный каталог FTP/SFTP с совпадающим `type`; переопределения SMB не поддерживаются.

Задайте `path` файлом или glob и `encoding` (по умолчанию `utf-8`).

## Результат

`output` — сам документ для одного файла либо список документов для нескольких. Это JSON-значение, а не DataFrame.

## Поведение и ограничения

Каждый файл целиком загружается и разбирается через `json.loads`; JSON Lines как поток документов не поддерживается. Несколько массивов сохраняются вложенными, а не объединяются плоско. Получение метаданных также загружает документы. Объём ограничен памятью worker.

## Примеры

Файл подключённого хранилища содержит `[{"id":1}]`. `output` — этот массив; два найденных файла дали бы внешний список их документов.

Значения параметров, без оболочки MCP patch:

```json
{
  "path": "incoming/orders.json",
  "encoding": "utf-8"
}
```

## Типовые ошибки

Ошибка декодирования/JSON: проверьте кодировку и один корректный документ в каждом файле. Неожиданная вложенность: учитывайте число найденных файлов при выборе JSON-пути.
