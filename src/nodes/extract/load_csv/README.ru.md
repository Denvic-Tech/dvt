# Чтение CSV

Тип ноды: `LoadCSV`.

## Назначение и выбор

Читает один или несколько CSV-файлов в DataFrame.

## Входы и настройка

Подайте объект S3, FTP/SFTP или SMB из выхода `connection` соответствующей ноды во вход `connection`. `path` задаётся относительно bucket/prefix, начального каталога или share; не дублируйте корень и не передавайте credentials. Необязательный `connection_overrides` поддерживает bucket/prefix/verify S3 и начальный каталог FTP/SFTP с совпадающим `type`; переопределения SMB не поддерживаются.

`path` поддерживает glob. `delimiter` по умолчанию запятая; поддерживается экранированная табуляция. `encoding=utf-8`, необязательные `usecols` и `dtypes` задают декодирование, выбор колонок и типы.

## Результат

`output` — Dask DataFrame из найденных файлов.

## Поведение и ограничения

Должен найтись хотя бы один файл. Схемы файлов должны быть совместимы; вывод типа по начальной выборке может пропустить смешанные значения далее. FTP-файлы скачиваются локально и читаются отложенными pandas-партициями. Получение метаданных тоже открывает данные. Отдельной настройки файлов без заголовка нет.

## Примеры

Подключите объект S3, в корне которого есть подходящие CSV с заголовками `id;amount`. Результат объединяет строки и сохраняет текстовые ID.

Значения параметров, без оболочки MCP patch:

```json
{
  "path": "incoming/orders-*.csv",
  "delimiter": ";",
  "dtypes": {
    "id": "string",
    "amount": "float64"
  }
}
```

## Типовые ошибки

Нет файлов: проверьте корень и шаблон. Ошибка декодирования/колонок: проверьте кодировку, разделитель и заголовок. Смешанные типы: задайте подходящие dtypes вместо вывода по выборке.
