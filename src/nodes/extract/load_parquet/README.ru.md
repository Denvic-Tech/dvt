# Чтение Parquet

Тип ноды: `LoadParquet`.

## Назначение и выбор

Читает Parquet-файл или dataset с сохранением записанной схемы.

## Входы и настройка

Подайте объект S3, FTP/SFTP или SMB из выхода `connection` соответствующей ноды во вход `connection`. `path` задаётся относительно bucket/prefix, начального каталога или share; не дублируйте корень и не передавайте credentials. Необязательный `connection_overrides` поддерживает bucket/prefix/verify S3 и начальный каталог FTP/SFTP с совпадающим `type`; переопределения SMB не поддерживаются.

Задайте `path` относительным путём файла/dataset. Необязательный `usecols` выбирает поля.

## Результат

`output` — Dask DataFrame; значения Hive-партиций восстанавливаются в колонки с учётом метаданных dataset.

## Поведение и ограничения

Используются pyarrow и схемы файлов, а не угадывание типов как CSV. FTP-dataset перечисляются рекурсивно, файлы читаются через временные локальные копии. Логическая схема DVT помогает восстановить типы/категории партиций. Части должны иметь совместимые схемы; получение метаданных не проверяет полное чтение.

## Примеры

Подключите хранилище с существующим dataset и этими колонками. Результат предоставляет только `id, amount`.

Значения параметров, без оболочки MCP patch:

```json
{
  "path": "datasets/orders",
  "usecols": [
    "id",
    "amount"
  ]
}
```

## Типовые ошибки

Dataset не найден: различайте путь файла и каталога. Нет поля/конфликт схем: проверьте части и сохранённые метаданные партиций. Не указывайте посторонние файлы.
