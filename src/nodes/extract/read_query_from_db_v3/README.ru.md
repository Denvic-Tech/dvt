# Чтение результата SQL

Тип ноды: `ReadQueryFromDBV3`.

## Назначение и выбор

Читает результат запроса как DataFrame с партициями. Для обычной выгрузки предпочтительны ReadTableFromDBV3 и low-code преобразования; необходимость SQL источника объясните в комментарии ноды.

## Входы и настройка

Соедините `GetExistDBConnection.connection` → `connection`. Задайте `sql_code`, не `query`, одним SELECT/WITH/set-operation выражением. `partition_col` — точная скалярная колонка/alias результата без SQL-кавычек. `partition_grouping`, `npartitions`, `max_rows_per_partition`, `limit` настраивают чтение.

## Результат

`output` — Dask DataFrame с полями результата запроса.

## Поведение и ограничения

Запрос должен подходить для партиционированного выполнения планировщиком чтения. Предпочтительны стабильные ключи без null. Настройки партиций не агрегируют бизнес-данные и не гарантируют порядок строк. Получение метаданных описывает колонки запроса через источник; невычисленный/пустой SQL может дать пустые метаданные. Это не доказывает успех полного выполнения.

Если `npartitions` не задан, планировщик оценивает целевое число по результату запроса и настройкам экземпляра. По умолчанию сегментация использует диапазоны для упорядочиваемых ключей без null, иначе — hash-сегменты. Явный режим range отклоняет null-ключи. `max_rows_per_partition` вызывает ошибку при слишком большом сегменте, а не разбивает его автоматически. Планирование и чтение могут выполнять запрос неоднократно, включая подсчёт и выборку образца; используйте стабильный результат и учитывайте нагрузку на источник. Ключ результата может также стать индексом, оставаясь колонкой данных.

## Примеры

Предположим, подключённая БД содержит эти колонки. Минимальный пример контракта выдаёт `id, amount`; для такого обычного чтения в реальном графе используйте ReadTableFromDBV3, если дополнительная логика источника не оправдывает SQL.

Значения параметров, без оболочки MCP patch:

```json
{
  "sql_code": "SELECT id, amount FROM orders",
  "partition_col": "id"
}
```

## Типовые ошибки

Нет колонки партиции: явно выберите её и задайте alias. Несколько выражений/нетабличный SQL запрещены политикой ноды. Проверьте диалект, права и поддержку группировки для ключа результата.
