# Чтение Excel

Тип ноды: `LoadExcel`.

## Назначение и выбор

Читает лист подходящих XLSX-книг в DataFrame.

## Входы и настройка

Подайте объект S3, FTP/SFTP или SMB из выхода `connection` соответствующей ноды во вход `connection`. `path` задаётся относительно bucket/prefix, начального каталога или share; не дублируйте корень и не передавайте credentials. Необязательный `connection_overrides` поддерживает bucket/prefix/verify S3 и начальный каталог FTP/SFTP с совпадающим `type`; переопределения SMB не поддерживаются.

`path` поддерживает glob. `sheet_name="0"` — первый лист; числовые строки задают индекс с нуля, остальные — имя. `header_row=0` также отсчитывается с нуля. Имена `usecols` имеют приоритет над `usecols_range` (например, `A:C`). Явные `dtypes`: `string`, `Float64`, `Int64`, `boolean`. `thousands`, `decimal="."` и необязательный `read_timeout_sec` управляют разбором.

## Результат

`output` — Dask DataFrame с отложенным чтением файлов.

## Поведение и ограничения

Использует openpyxl с сохранёнными значениями формул; формулы Excel не вычисляет. Для вывода схемы берёт 32 строки, при расчёте читает выбранные листы файлов целиком. Некорректные числовые/boolean-ячейки при явной нормализации становятся пропусками. Ошибки Excel считаются пропусками. Большие отдельные книги всё равно требуют памяти. Таймаут прекращает ожидание, но не может принудительно завершить уже работающий поток чтения.

## Примеры

Подключите хранилище с XLSX-листом `Orders` и колонками `id, amount`. Результат содержит строки данных; корректные суммы с десятичной запятой становятся числами.

Значения параметров, без оболочки MCP patch:

```json
{
  "path": "incoming/orders.xlsx",
  "sheet_name": "Orders",
  "dtypes": {
    "id": "string",
    "amount": "Float64"
  },
  "decimal": ","
}
```

## Типовые ошибки

Нет листа/колонок: проверьте имена и строку заголовка. Числовые имена листов трактуются как индексы. Пустые формулы могут не иметь сохранённого результата в книге. Для смешанных колонок используйте поддерживаемые явные dtypes.
