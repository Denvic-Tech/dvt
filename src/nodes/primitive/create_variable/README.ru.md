# Создание переменной

## Назначение и выбор

`CreateVariable` создаёт одну типизированную пользовательскую переменную для следующих нод. Для нескольких переменных или управления входным набором используйте `ManageVariables`.

## Входы и настройка

Задайте `name`, `type` и `value`. Типы: `STRING`, `BOOLEAN`, `INT`, `FLOAT`, `DATETIME`, `TIMEDELTA`, `JSON`. `is_list_type=false` означает скаляр, true — список элементов поддерживаемого выбранного типа. `nullable=false` запрещает вычисленный null, если не задан `default`. `default` должен быть литералом, без ребра или выражения. Для значений-выражений соедините upstream `output_variables` → `input_variables` и используйте актуальную схему выражений.

## Результат

`output_variables` содержит именованную типизированную переменную. Подключите эту карту переменных к `input_variables` потребителя; это не порт DataFrame.

## Поведение и ограничения

Значения приводятся к объявленному типу. Если результат null, явно заданный `default` имеет приоритет перед `nullable`; иначе nullable разрешает null, а в оставшемся случае возникает ошибка. Отсутствующий default — маркер `UNSET`, отличающийся от явного `default=null`: последний считается заданным и может вернуть null даже при `nullable=false`. Отсутствующая входная переменная или неразрешённое выражение — не вычисленный null; default не служит обработчиком отсутствующих переменных. Default не исправляет некорректное ненулевое значение или ошибку выражения. Режим метаданных может сохранить невычисленное выражение; полное выполнение должно его вычислить. Для списков поддерживается только форма одиночного выражения.

## Примеры

Литеральные значения настройки, без оболочки MCP patch:

```json
{"name":"batch_size","type":"INT","value":1000}
```

Выходная карта содержит целочисленную `batch_size=1000`.

```json
{"name":"region","type":"STRING","value":null,"default":"unknown","nullable":false}
```

Здесь результат — `region="unknown"`. В MCP patch кодируйте литеральный null по схеме значения входа: голый null при обновлении удаляет сохранённый вход.

## Типовые ошибки

Ошибка null: задайте осмысленный литеральный default или разрешите nullable. Ошибка преобразования: согласуйте значение и тип. Невычисленное выражение: проверьте рёбра входных переменных и имена. Прямая ссылка на переменную как значение определения не поддерживается; используйте допустимое выражение.
