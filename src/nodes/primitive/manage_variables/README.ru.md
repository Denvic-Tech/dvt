# Управление переменными

Тип ноды: `ManageVariables`.

## Назначение и выбор

Определяет или переопределяет несколько типизированных пользовательских переменных. Для одного независимого определения используйте `CreateVariable`.

## Входы и настройка

Подключите входные карты в `input_variables`. Настройте `defined_variables`: имя → спецификация с `type` и ровно одним из литерального `value` или выражения `value_input`. Необязательные `is_list_type=false`, `nullable=false`, `default` следуют правилам CreateVariable.

## Результат

`output_variables` содержит итоговую карту переменных, включая определения, заменяющие совпавшие имена.

## Поведение и ограничения

Каждое выражение вычисляется по входным переменным, а не по более ранним определениям той же ноды. Для зависимых определений используйте цепочку нод. Явный default применяется к вычисленному null до nullable; отсутствие default отличается от default=null. Режим метаданных может выдать невычисленные значения, полный должен их разрешить. Defaults должны быть литералами.

## Примеры

Выходная карта включает `region=EU` и целочисленную `batch_size=1000`. Подключите её к `input_variables` следующих нод.

Значения параметров, без оболочки MCP patch:

```json
{
  "defined_variables": {
    "region": {
      "type": "STRING",
      "value": "EU"
    },
    "batch_size": {
      "type": "INT",
      "value": 1000
    }
  }
}
```

## Типовые ошибки

Оба/ни одного поля значения: задайте ровно одно. Неизвестное имя выражения: проверьте входные рёбра или разделите зависимые определения. Неверный тип/null: исправьте значение или политику default.
