# Запись CSV

Тип ноды: `SaveCSV`.

## Назначение и выбор

Выгружает DataFrame в CSV подключённого хранилища.

## Входы и настройка

Подайте объект S3, FTP/SFTP или SMB из выхода `connection` соответствующей ноды во вход `connection`. `path` задаётся относительно bucket/prefix, начального каталога или share; не дублируйте корень и не передавайте credentials. Необязательный `connection_overrides` поддерживает bucket/prefix/verify S3 и начальный каталог FTP/SFTP с совпадающим `type`; переопределения SMB не поддерживаются.

Подключите `df`. Укажите `path` с именем файла (суффикс `.csv` добавляется при отсутствии). Defaults: `delimiter=","`, `encoding="utf-8"`, `index=false`, `header=true`, `single_file=true`.

## Результат

Создаёт CSV-файлы; выходного порта DataFrame нет.

## Поведение и ограничения

Запись вычисляет вход. В одном файле заголовок пишется один раз; в многофайловом режиме имена частей определяет Dask. CSV не сохраняет типизированную схему. Существующая цель может быть перезаписана; режима append/upsert нет. После ошибки могут остаться частичные файлы.

## Примеры

Подключите DataFrame и хранилище с правом записи. По относительному пути появляется CSV с заголовками и без колонки индекса.

Значения параметров, без оболочки MCP patch:

```json
{
  "path": "reports/orders.csv",
  "delimiter": ";",
  "index": false,
  "header": true,
  "single_file": true
}
```

## Типовые ошибки

Ошибка пути/прав: проверьте корень и доступ на запись. Лишняя колонка индекса: задайте index=false. После успеха проверьте файл; после ошибки проверьте частичный результат перед повтором.
