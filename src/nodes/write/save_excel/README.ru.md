# Запись Excel

Тип ноды: `SaveExcel`.

## Назначение и выбор

Создаёт XLSX-книги из DataFrame. Выгружает данные, не загружает и не сохраняет оформление существующей книги.

## Входы и настройка

Подайте объект S3, FTP/SFTP или SMB из выхода `connection` соответствующей ноды во вход `connection`. `path` задаётся относительно bucket/prefix, начального каталога или share; не дублируйте корень и не передавайте credentials. Необязательный `connection_overrides` поддерживает bucket/prefix/verify S3 и начальный каталог FTP/SFTP с совпадающим `type`; переопределения SMB не поддерживаются.

Подключите `df`. Задайте `path` с именем файла; `.xlsx` добавляется при необходимости. Defaults: `sheet_name="Sheet1"`, `index=false`, `header=true`, `single_file=true`.

## Результат

Создаёт одну книгу или файлы `<stem>-part-00000.xlsx` и далее. DataFrame на выход не выдаётся.

## Поведение и ограничения

Один файл требует материализации всего DataFrame в памяти worker. Режим частей пишет книгу на каждую Dask-партицию, а не несколько листов одной книги. Учитывайте ограничения Excel вместе с заголовком/индексом: 1 048 576 строк и 16 384 колонок на лист. Существующие файлы открываются на перезапись. Даты с часовым поясом могут потребовать преобразования до выгрузки.

## Примеры

Подключите DataFrame и объект S3. Результат — XLSX под bucket/prefix соединения с листом `Orders`.

Значения параметров, без оболочки MCP patch:

```json
{
  "path": "reports/orders.xlsx",
  "sheet_name": "Orders",
  "index": false,
  "header": true,
  "single_file": true
}
```

## Типовые ошибки

Нехватка памяти/лимит листа: уменьшите данные или используйте партиции размером не больше листа. Неверное имя листа или даты с поясом: нормализуйте до выгрузки. После успеха проверьте размер и путь файла.
