# Замечания по реализации, найденные при подготовке справок нод

Проверено 23 сентября 2026 года. Эти замечания зафиксированы отдельно от пользовательских
README: справки описывают текущее поведение, исправления runtime в эту работу не входят.
Каждый пункт требует отдельного решения и регрессионной проверки перед изменением поведения.

| Нода | Наблюдаемое расхождение | Где проверить | Что учитывать до исправления |
| --- | --- | --- | --- |
| `ReadTableFromDBV3` | Поле `time_zone` объявлено, но не передаётся в путь чтения и не применяется при построении метаданных. | [node.py](../src/nodes/extract/read_table_from_db_v3/node.py), `process` / `infer_metadata` | Не рассчитывать на изменение часового пояса этим параметром; использовать явное преобразование. |
| `AddTimeDeltaToDataFrame` | `weeks`, `milliseconds`, `microseconds` объявлены, но не включены в создаваемый `DateOffset`; используемые компоненты приводятся к int. | [node.py](../src/nodes/transform/df_add_time_delta/node.py), `process` | Эти три поля не дают ожидаемого сдвига; дробные компоненты не сохраняются. |
| `JsonToDataFrame` | `orient` объявлен, но не используется: dict оборачивается в список, затем вызывается `pd.DataFrame`. | [node.py](../src/nodes/json/json_to_df/node.py), `process` | Не считать ноду обратной к `DataFrameToJson` во всех orient-режимах. |
| `DataFrameSelectColumns` | При пустом `columns` метод возвращается, не устанавливая `output`. Имя индекса исключается из выбора, даже если одноимённая колонка есть в данных. Неизвестные имена молча отфильтровываются. | [node.py](../src/nodes/transform/df_select_columns/node.py), `process` | Передавать непустой проверенный список, учитывать совпадение имени колонки и индекса. |
| `ExpandJSON` | `max_depth` ограничивает анализ структуры, но не рекурсию фактического flatten. `max_total_rows` применяется к каждой исходной записи отдельно. | [node.py](../src/nodes/json/flatten_dict/node.py), `analyze_structure`, `flatten`, `flatten_and_explode_optimized`, `process` | Не использовать эти параметры как гарантированный глобальный предел глубины и числа строк всего результата. |

Параметры и примеры остальных справок сверены с полями нод и вложенными схемами.
Описанные здесь особенности сохранены; публичные API и схемы не менялись.
